Ex-8-2: Regression Tables, with an AI Assistant

Abstract
Make Tables

This is an in-class exercise. Before class, work through the lecture 08-2: Regression Tables (and 08-1 for the table standard). In class, you work through the worksheet with an AI assistant writing the code. Your job is everything the AI cannot do: knowing which models you meant, how many observations each should use, and judging whether the table shows them.

Setup

  1. Use the ch8-practice project from Ex-8-1. If you do not have it, follow the setup of Ex-8-1.
  2. Download the worksheet, ex-8-2.qmd, into ch8-practice/analysis, and make sure 8-1-county-crops.csv is in ch8-practice/data.
  3. Ask your AI assistant to install modelsummary if you have not already.
  4. Open the worksheet and start at Task 1.
It worked if

Typing here::here() in the Console prints the path to ch8-practice and nothing longer.

If here::here() prints a path ending in analysis, the .Rproj file was not recognised. here only accepts a .Rproj file whose first line starts with Version:, which every project created in RStudio (File, New Project) has. An empty .Rproj file made any other way does not count.

Answers

Open each one only after you have tried the task.

Task 1: Look

What you should find

A. 1956 data rows.

B. Only soy_yield, written as NA. Every Colorado row has NA there: the data has no soybean yields for Colorado at all. Kansas and Nebraska rows have them in some county-years and not in others.

Task 2: Count before you predict

What you should find

soy_yield is missing on 856 of the 1956 rows: all 154 Colorado rows, 349 of 534 in Kansas and 353 of 1268 in Nebraska. No other column has missing values.

Prediction. lm() leaves out every row with a missing value in a variable the model uses:

  1. Corn: 1956, every row, since none of its variables has missing values.
  2. Soybeans: 1100, the rows with a soybean yield.

Task 3: The regression table

What you should find

The table should look like this (robust standard errors in parentheses):

Corn and soybean yields (bushels per acre) and weeks of drought, May to September
(1) Corn (2) Soybeans
Linear regressions, one per column. Robust standard errors (HC1) in parentheses.
Extreme drought: US Drought Monitor categories D3 and D4. Severe drought: category D2.
County-years without a soybean yield (all of Colorado) are left out of column (2).
Weeks of extreme drought -1.08 -0.16
(0.15) (0.10)
Weeks of severe drought -0.89 -0.33
(0.13) (0.05)
Constant 182.94 56.03
(0.58) (0.25)
Observations (county-years) 1,956 1,100

Observation checks: 1,956 and 1,100, matching the prediction from Task 2.

Checklist answers that are often “no” in the AI’s first table: no note saying which standard errors; headers (1) and (2) that do not say which crop each model explains; raw names such as weeks_extreme; no note that column (2) has fewer observations, and why.

A message from this table: “Each additional week of extreme drought goes with corn yields 1.1 bushels per acre lower, and soybean yields 0.16 bushels per acre lower.” Corn yields are larger to begin with (on average 178 against 55), so you might also compare in percent of the average: -0.6% against -0.3%. Hold on to this message until Task 4.

Task 4: The same counties?

What you should find

A. Column (1) has every county-year; column (2) only those with a soybean yield. So column (1) also includes all of Colorado, and 349 Kansas and 353 Nebraska county-years that column (2) does not. Colorado is missing from column (2) entirely.

B. Without regression. Average corn yield in county-years with extreme drought, minus the average in county-years without:

Rows used Difference (bushels per acre) Rows
All rows -10.7 1,956
Only rows with a soybean yield -3.2 1,100

On the rows the soybean model uses, corn yields fall by about a third as much in drought. So a corn column on all rows and a soybean column on fewer rows are not comparing like with like.

C. The regression confirms it. The third column, corn on only the 1100 rows with a soybean yield (Kansas and Nebraska only):

Weeks of extreme drought Robust standard error Observations
(1) Corn, all rows -1.08 (0.15) 1,956
(2) Soybeans -0.16 (0.10) 1,100
(3) Corn, rows with a soybean yield -0.11 (0.21) 1,100

So the message from Task 3 does not hold as written: comparing column (1) with column (2) compares different counties as much as different crops. On the same county-years, the corn estimate is about 0.1 times its size in column (1), roughly a tenth. The data cannot tell us which crop is hurt more.

A side note on the standard errors, if you have met them in a statistics course: on the same county-years, neither estimate is as large as twice its standard error, so neither is clearly different from zero.

This table cannot say why the corn result depends so much on which rows are used; that would be a question for further work, not something to guess.

D. Show the table with column (3), or with columns (2) and (3) only if the comparison of the crops is the message. The notes say: which standard errors; what the drought categories are; and that column (3) uses only county-years with a soybean yield, with the number of observations shown for every column.

Task 5: Alex’s code

Answers

A. Read the data and remove every row with a missing value in any column; estimate corn yield on the two drought columns; estimate soybean yield on the same; put both in a table with robust standard errors, showing only the weeks of extreme drought row, labelled.

B. 1100. na.omit() removed every row without a soybean yield, so the corn model lost all of Colorado and many Kansas and Nebraska years, although none of its own variables has a missing value. Alex would expect 1956. The corn estimate is -0.11, the same as column (3) in Task 4, not -1.08.

C. coef_map lists only weeks_extreme, so the severe drought rows and the constants are dropped, with nothing saying so. Against the table standard: the bottom rows keep AIC, BIC and other statistics the message does not need, the label has no units, and there is no title and no note saying which standard errors are shown.

D. Using only the rows with both yields is the right choice when the message is a comparison of the two crops on the same county-years, as in Task 4. What was wrong is that nobody decided it: it happened as a side effect of a cleaning step, and the table does not say so. If it is the choice, the note must say “Both models use only the 1100 county-years with a soybean yield (Kansas and Nebraska).”

E. The number of observations of each model against the number expected (catches na.omit()), and every coefficient of each model against the rows of the table (catches coef_map).
